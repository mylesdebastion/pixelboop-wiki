# Color & Music Theory

Pixelboop maps musical pitch directly to color, creating a synesthetic experience where you can "see" the music. There are two color maps — **harmonic** (the default) and **chromatic** (an alternative you can switch to) — and they assign different colors to the same twelve notes.

:::note What changed on this page
This page used to show only the chromatic map below, without saying it was one of two options. The app's default is harmonic, so the colors you actually see in the grid are the ones in the Harmonic Color Map. If you learned the old chromatic table and the app's colors never matched it, this is why.
:::

## Harmonic Color Map (default)

Note colors are arranged by the **circle of fifths** instead of by pitch order. Consonant intervals (fourths and fifths) land on adjacent hues, and the tritone lands on the opposite hue, so notes that sound harmonious also look similar, and clashing notes visibly contrast. Because a semitone is not a harmonically close interval, colors do **not** run in a smooth rainbow from C to B the way the chromatic map does — that's expected.

## Chromatic Color Map (alternative)

Turn **Harmonic Colors** off in the [Rainbow Menu](../GettingStarted/RainbowMenu) to switch to this map instead. Each of the 12 musical semitones gets a color from the spectrum in straight pitch order, so colors run smoothly from red at C to purple at B.

## Track Colors

Each track has a base theme color that helps differentiate it on the grid.

- **Melody:** Blue-Purple (`#4D2EF2`)
- **Chords:** Cyan-Green (`#00E68C`)
- **Bass:** Yellow (`#F2E600`)
- **Rhythm:** Red-Orange (`#FF3000`)
