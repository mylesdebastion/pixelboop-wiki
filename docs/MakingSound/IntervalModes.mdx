# Interval Modes

**Interval modes** control which musical interval separates each row of a pitch track. Changing the interval mode changes what note you get when you tap a given row — from tight, stepwise intervals to wide, open ones — without changing the key or scale you're in.

Interval modes apply to the three pitch tracks: **Melody**, **Chords**, and **Bass**. See [Tracks & Sounds](Tracks.mdx) for how those tracks are laid out on the grid.

## The 8 interval modes

Cycling through column 3 (see below) steps through these modes in order:

| Mode | Tooltip | Character |
| :--- | :--- | :--- |
| **Pentatonic** | `PENTA` | The default — a safe, pop/folk-friendly five-note framework. Hard to land on a wrong-sounding note. |
| **Jazz** | `JAZZ` | Emphasizes the 3rd, 7th, and 9th — the notes that give a chord its jazz color. |
| **3rds** | `3RDS` | Every other scale degree — classic stacked-thirds harmony. |
| **4ths** | `4THS` | Wider spacing between rows — an open, modern "quartal" sound. |
| **5ths** | `5THS` | Power-chord-style spacing. |
| **7ths** | `7THS` | Wide skips built from 7th intervals. |
| **2nds** | `2NDS` | Adjacent scale degrees — the tightest, most stepwise sound. |
| **Chromatic** | `CHROM` | Every row is one semitone apart, spanning the full range with no scale snapping. |

## Changing the interval mode (hold column 3)

Each pitch track has a notes column at **column 3** — the same column that shows the track's current scale notes. Hold anywhere in that column on the Melody, Chords, or Bass track:

1. **Hold ~0.5 seconds** — the interval mode selection lights up, starting from the track's current mode.
2. **Keep holding** — the highlighted mode steps forward roughly every 0.7 seconds, cycling through the 8 modes above in order (wrapping back to Pentatonic after Chromatic). Each step gives a light haptic tap and shows the mode's name.
3. **Release** — the highlighted mode is confirmed and applied.

Releasing before the first step (before ~0.5 seconds) is just a quick tap — nothing changes.

:::note
On the **Rhythm** track, tapping column 3 does something different: it switches drum banks. The hold-to-cycle interval gesture only applies to the Melody, Chords, and Bass tracks.
:::

## Linked intervals (new default)

:::tip New in 1.1.2
Changing the interval mode on any one pitch track now applies it to **Melody, Chords, and Bass together** by default. A single hold-and-release on any of the three retunes all three tracks to the new interval mode at once.
:::

To go back to cycling each track's interval mode independently, open the **Rainbow Menu → Interface** group and turn on **Individual intervals per track**. With that on, holding column 3 on a track only changes that track's own interval mode.

## Jams and interval modes

A saved jam remembers whichever interval mode each track was using, and loads with those settings intact — even if the tracks end up with different interval modes from each other. Linking only takes effect the next time you hold-and-release column 3 on a pitch track; opening a jam never retroactively forces all three tracks onto the same interval mode.
