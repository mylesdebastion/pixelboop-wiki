# Color & Music Theory

Pixelboop maps musical pitch directly to color, creating a synesthetic experience where you can "see" the music.

## Chromatic Color Map

Each of the 12 musical semitones is assigned a specific color from the spectrum. This helps you identify notes and harmonic relationships visually.

## Track Colors

Each track has a base theme color that helps differentiate it on the grid.

- **Melody:** Yellow/Gold (`#F7DC6F`)
- **Chords:** Cyan/Teal (`#4ECDC4`)
- **Bass:** Blue (`#45B7D1`)
- **Rhythm:** Red/Coral (`#FF6B6B`)
