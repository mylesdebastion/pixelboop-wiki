# Drum Banks

The Rhythm track uses **sampled drums** organized into 4 banks. Each bank assigns different drum sounds to the 4 rhythm rows.

## General MIDI Drum Map

When using MIDI with external gear, the rhythm track sends standard GM drum notes on **Channel 10** (default).

| Note | Drum Sound |
|------|------------|
| 35 | Acoustic Bass Drum |
| 36 | Bass Drum 1 |
| 37 | Side Stick |
| 38 | Acoustic Snare |
| 39 | Hand Clap |
| 40 | Electric Snare |
| 42 | Closed Hi-Hat |
| 45 | Low Tom |
| 46 | Open Hi-Hat |
| 49 | Crash Cymbal 1 |
| 51 | Ride Cymbal 1 |
| 56 | Cowbell |

These mappings follow the General MIDI (GM) standard, ensuring compatibility with GM-compliant synths and DAWs.
